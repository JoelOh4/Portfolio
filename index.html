Projects

Business Portal (Vertex Holdings)

We developed a portal to enable clients of Vertex Holdings to connect and learn more about each other. The project utilized Django Rest Framework for a robust backend API and Vitest for efficient testing. The result is a seamless, user-friendly platform that fosters interaction and collaboration among clients.

Workload Tracker (Octagon Development Pte Ltd)

Development of a Workload Tracker to help Octagon Development manage construction worker timesheets. The app automates clock-in and clock-out records using beacon proximity and ensures accurate tracking of work hours in real-time. It leverages technologies like React, Node.js, and MySQL, providing an efficient and user-friendly solution for managing employee time data.
